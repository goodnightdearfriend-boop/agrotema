# Agrotema

Сайт-каталог сільгосптехніки Agrotema (Лебедин, Сумська обл.).
Телефон: +380 99 466 71 28 · Пошта: agrotema.ua@ukr.net · TikTok: @agrotema.ua

## Як влаштовано
- `index.html` — сторінка сайту.
- `data/listings.js` — усі оголошення (назва, ціна, опис, місце).
- `i/<id>-01.jpg …` — фото оголошень з водяним знаком; `t/<id>.jpg` — обкладинки карток.

Сайт публікується через GitHub Pages з гілки `main`.
